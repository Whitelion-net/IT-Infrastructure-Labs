# Lab 03 — Windows Server 2022 Administration

## Lab Objective

Practice basic Windows Server administration, system diagnostics, user management, services, Event Viewer, firewall configuration, and remote management.

---

## Exercise 1 — Initial Server Configuration

### Steps
1. Started Windows Server 2022 in the virtual machine.
2. Opened Server Manager.
3. Reviewed the Local Server configuration.
4. Renamed the server to `SERVER01`.
5. Restarted the server to apply the new hostname.
6. Verified that the new computer name was applied successfully.

---

## Exercise 2 — Network Configuration and Diagnostics

### Steps
1. Opened PowerShell.
2. Checked the server's IP configuration.
3. Identified the IPv4 address, subnet mask, default gateway, and DNS configuration.
4. Checked the status of the network adapter.
5. Tested the local TCP/IP stack using the loopback address `127.0.0.1`.
6. Tested external network connectivity.
7. Tested DNS name resolution using `nslookup`.
8. Confirmed that the server had working network and Internet connectivity.

---

## Exercise 3 — Server Roles and Features

### Steps
1. Opened Server Manager.
2. Reviewed the Roles and Features section.
3. Used PowerShell to view available Windows Server roles and features.
4. Identified which roles and features were currently installed.
5. Became familiar with how Windows Server functionality is organized through roles and features.

---

## Exercise 4 — Windows Firewall

### Steps
1. Opened PowerShell as Administrator.
2. Checked the status of Windows Firewall profiles.
3. Reviewed existing Windows Firewall rules.
4. Created a temporary inbound firewall rule allowing ICMPv4 traffic.
5. Verified that the new firewall rule was created.
6. Removed the temporary firewall rule after testing.
7. Confirmed that the temporary rule was successfully removed.

---

## Exercise 5 — Windows Services

### Steps
1. Used PowerShell to display Windows services.
2. Located the Windows Time service (`W32Time`).
3. Checked the service status and configuration.
4. Started/restarted the Windows Time service.
5. Opened the Services management console using `services.msc`.
6. Located the same service through the graphical interface.
7. Compared service management through PowerShell and the GUI.

---

## Exercise 6 — Event Viewer and System Logs

### Steps
1. Opened Windows Event Viewer.
2. Navigated to `Windows Logs → System`.
3. Reviewed system events generated by Windows Server.
4. Filtered the log to display:
   - Critical events
   - Errors
   - Warnings
5. Selected an event and reviewed its details.
6. Used PowerShell to retrieve Windows Event Log information.
7. Saved a screenshot of an example system event.

---

## Exercise 7 — Local User and Group Management

### Steps
1. Opened PowerShell as Administrator.
2. Created a secure password variable.
3. Created a temporary local account named `labuser`.
4. Added `labuser` to the local `Users` group.
5. Verified that the account existed and was enabled.
6. Checked the members of the `Users` group.
7. Confirmed that `labuser` was a member.
8. Removed the temporary `labuser` account after testing.
9. Verified that the account had been removed.

---

## Exercise 8 — Windows Remote Management

### Steps
1. Opened PowerShell as Administrator.
2. Checked the status of the Windows Remote Management (`WinRM`) service.
3. Verified that the WinRM service was running.
4. Reviewed the WinRM configuration.
5. Inspected the WSMan remote management configuration.
6. Verified the `AllowUnencrypted` setting.
7. Became familiar with how Windows Server supports remote administration.

---

## Lab Summary

During this lab, I practiced:

- Basic Windows Server 2022 administration
- Server configuration
- Network diagnostics
- Server roles and features
- Windows Firewall management
- Windows Services management
- Event Viewer and system log analysis
- Local user and group administration
- PowerShell administration
- Windows Remote Management (WinRM)

The lab provided hands-on experience with common Windows Server administration and diagnostic tasks.
